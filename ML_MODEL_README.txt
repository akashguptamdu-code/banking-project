ML source code: ml_model.py
Dataset: European_Bank.csv
Run: pip install pandas numpy scikit-learn xgboost joblib
Then: python ml_model.py
The script trains Logistic Regression, Decision Tree, Random Forest, Gradient Boosting and XGBoost; evaluates Accuracy, Precision, Recall, F1 and ROC-AUC; and creates churn probabilities and Low/Medium/High risk bands.
